# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/) conventions.

## [1.0.0] - 2026-09-01

### Changed

- Renamed the application from DeepWork HUD to DeepHUD while preserving existing local data and backup compatibility.

### Added

- Production timer controls: stopwatch, countdown, Deep Work, Pomodoro, custom intervals, skip, and ±5 minute adjustment.
- Compact/full HUD modes, corner snapping, customizable accents, tray lifecycle, close-to-tray, and login startup.
- Configurable global shortcuts including one-command Deep Work start.
- Searchable/filterable/editable history with CSV/JSON export and full JSON backup/restore.
- SQLite project/task catalog, daily and weekly statistics, goals, streaks, and active/paused-time accounting.
- Desktop notifications, optional sounds, five-minute warnings, and configurable native idle behavior.
- Linux `.deb`/AppImage, Windows `.exe`/`.msi`, and Intel/Apple Silicon macOS DMG packaging.
- Cross-platform CI, tagged draft releases, release version validation, SHA-256 checksums, automated tests, and project documentation.

## [0.3.0] - 2026-08-31

- Added structured focus sessions, SQLite history, productivity dashboard, projects, goals, streaks, notifications, and sounds.

## [0.2.0] - 2026-08-31

- Added themes, accents, opacity, sizes, positions, click-through, presets, settings, and global shortcuts.

## [0.1.0] - 2026-08-31

- Initial floating stopwatch/countdown HUD.
