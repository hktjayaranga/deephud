# Security policy

## Supported versions

Security fixes are provided for the latest stable release.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Security → Report a
vulnerability** feature. Do not open a public issue containing exploit details,
private session data, or a personal database.

Include the affected version, operating system/version, reproduction steps, and
expected impact. Reports will be acknowledged as soon as practical.

## Data boundary

DeepHUD has no analytics, advertising, account system, or application
network client. User settings and the SQLite database remain on the device.
Export and restore occur only after an explicit file-picker action.
